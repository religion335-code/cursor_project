# 尋找加盟主｜招商手冊

目標：36 個月內找到 **6 位** 區域工廠加盟主，不是 60 位開店創業者。  
原則：意向多、簽約少、公開數字誠實。

---

## 1. 訊息一句話

**宜蘭蜜谷要在全台找「冰磚工廠」負責人，不是再招冰店。**  
立足宜蘭母廠，區域專屬製造，真水果、無添加，供你自己城市的冰店與餐飲。

禁止使用：保證月入、加盟金含一切、免權利金就能躺著賺、限時名額只剩一個。

---

## 2. 找誰、在哪找

| 管道 | 做法 | 預期對象 |
| --- | --- | --- |
| 宜蘭旗艦店與母廠見習 | 開放「工廠說明日」，先吃冰再看廠 | 認真者 |
| 食品機械、冷凍物流、工業區社群 | 談產能與用電，不談網美 | 資本型 |
| 既有冰店想垂直整合 | 用方案 C 經銷當觀察期，再升工廠 | 產業內 |
| 餐飲連鎖後勤主管 | 私洽，不公開喊價 | 專業經理人 |
| 地方工業策進會、青年創業資源 | 說明合法設廠，不走夜市攤車展 | 法人 |
| 舊門市加盟詢問名單 | 分類：只想來開店的導入經銷；有廠房／資金的深談 | 過濾 |

不主打 YES 加盟、開店雜誌的「98 萬含裝潢」版位，避免招來錯誤客層。若刊登，標題必須出現「工廠／工業區／380 萬起」。

---

## 3. 篩選漏斗

```
詢問 → 看完揭露摘要與風險 → 資金與廠房條件問卷
  → 宜蘭試吃＋母廠參觀 → 區域評估（競品、夜市、工業區）
  → 正式揭露書（10 日）→ 契約審閱（5 日）→ 簽約
```

任一關用「保證賺」逼問的，直接淘汰。

問卷最低門檻：

- 可動用資金含週轉 ≥ 500 萬（方案 A）
- 能在 6 個月內取得合法廠址
- 本人或股東願意駐廠至少前 18 個月
- 書面同意無添加抽檢

---

## 4. 區域出擊順序

1. **桃園或北北基**（第一座樣板，離宜蘭支援近、市場夠大）  
2. **中彰投**  
3. **高屏**  
4. **雲嘉南、竹苗**  
花東不開工廠招商，只做經銷與季節支援。

同一時間深入培養的工廠候選人 **每區不超過 3 位**，避免放話「這區已滿」卻又收下一組訂金。

---

## 5. 面談大綱（90 分鐘）

1. 品牌為何堅持真水果（以及成本後果）  
2. 為何門市加盟改工廠  
3. 專屬區地圖與不能做的事  
4. 投資區間與淡季  
5. 總部做不到的事  
6. 加盟主要自己跑 B2B  
7. 商標與公司整備現況（必須坦白）  
8. 下一步：參觀母廠，不收費

---

## 6. 第一年成功長相（給候選人對齊預期）

- 合法工廠登記完成  
- 15 個以上每週固定出貨的點  
- 稽核 B 以上  
- 淡季仍能支付電費與兩名人事  
- 沒有客訴變成新聞

不是：開幕排到巷口、網紅來拍、第二個月回本。
