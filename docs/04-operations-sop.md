# 區域冰磚工廠｜營運綱要（開業前 SOP 目錄）

本文件是總部給首座區域廠的「必須寫成現場可執行」的目錄。細部配方、溫度、時間屬營業秘密，只在訓練與受控文件提供。

---

## 1. 廠房最低條件

- 工業或符合食品工廠使用分區，可辦工廠登記與食品業者登錄（工廠／製造場所）
- 建議 60–120 坪：原料區、前處理、煮製／調漿、製磚、急速冷凍、包裝、成品庫、更衣室、清潔間
- 動線：污／淨分離；水果土砂不進入調漿區
- 三相電力、排水、防滑地坪、蟲鼠防治
- 冷凍庫至少兩溫層：原料／水果 vs 成品冰磚，禁止混放未包冰與生鮮肉品（廠內不得加工非相關葷食）
- 備用水與製冰用水符合飲用水標準；每年檢驗

不通過現勘不得支付工程尾款、不得開業。

---

## 2. 製程 CCP（概念）

| 點 | 控制什麼 |
| --- | --- |
| 水果驗收 | 產地、農藥殘留憑證或抽驗頻率、腐損剔除 |
| 乳品驗收 | 溫度、效期、來源 |
| 調漿 | 糖度、配方秤量雙人複核、過敏原（乳、花生） |
| 製磚 | 時間、冷凍液、中心溫度 |
| 脫模包裝 | 人員手套、批號、重量 |
| 儲運 | 成品 ≤ 指定溫度；配送車溫度紀錄；拒收解凍回凍 |
| 清潔 | 每日 SOP、過敏原班次分隔（花生日／水果日） |

每批留樣於獨立冷凍空間，保存至效期後 7 日。

---

## 3. 無添加紅線（抽檢即停權）

禁止：色素、香精、糖精、乳化劑、防腐劑、合成水果調味粉、水果濃縮汁（契約另列允許的例外，例如檸檬酸用於特定水果抗氧化，必須書面）。

允許：生鮮或冷凍水果、乳品、糖、既定堅果與豆類、茶葉等總部核准清單。

---

## 4. 人員

開業編制建議：廠長（可為加盟主）＋製程 1＋配送／業務 1。旺季再加計時。  
所有出貨簽字人員須通過總部認證，證照有效 24 個月。

---

## 5. 出貨與經銷

- 最低出貨溫度與保溫箱規範
- 單據必含：批號、顆數、口味、出廠溫度、車號
- 經銷契約由總部範本，區域廠簽署
- 客訴 24 小時內通報總部；疑似食安 2 小時

---

## 6. 淡季月曆（必須排產）

| 月份 | 重點 |
| --- | --- |
| 5–9 | 水果磚、觀光與夜市 |
| 10–11 | 芋頭南瓜花生、學校社團、活動 |
| 12–2 | 熱甜湯半成品、年節禮盒、旅館 OEM |
| 3–4 | 草莓季、設備保養、經銷回訪 |

---

## 7. 稽核評等

A：可發展經銷、可申請第二條產線  
B：限期改善  
C：停招經銷、限制新口味  
D：停權

評等項目：添加物、批號、溫度、清潔、客訴、系統費、跨區。
