## （五）商圈／區域經營方案

- 採 **縣市群集之專屬製造區**，非單一路口商圈。
- 36 個月規劃：北北基、桃園、竹苗、中彰投、雲嘉南、高屏各至多一廠；宜蘭縣保留母廠。
- 同一專屬區不重複授權第二製造廠，除非現有廠連續兩季無法滿足已核准訂單且總部書面認定。
- 授權經銷點不具專屬權，但必須向該區工廠進貨。
- 總部應於正式揭露時列出：**目前已簽約區域、籌備中區域、仍開放區域。**（草案階段：全部尚未簽約。）

## （六）加盟經營關係之限制

1. 僅得於專屬區設廠與批發。  
2. 產品必須依總部配方與「無添加」清單；抽檢不合格得立即停權。  
3. 競業：契約期間及結束後 18 個月，不得在專屬區經營同類冰磚製造供應。  
4. 不得將加盟權、商標使用權轉讓，除非總部書面同意並向受讓人重新訓練。  
5. 白牌 OEM 產線若經核准，必須空間、批號、包材隔離，且不得使用蜜谷商標。  
6. 最低採購：無最低香精粉採購；有 **最低識別包材使用率 80%**（蜜谷出貨必須可被下游識別）。  
7. 資訊系統：出貨單、溫度紀錄、批號須依總部格式保存三年。

## （七）契約變更、終止及解除

| 情形 | 處理 |
| --- | --- |
| 加盟主審閱期內不簽 | 不收費；若已收意向，零元 |
| 總部未完成商標／公司整備仍簽約 | 加盟主可解除，已收加盟金全退 |
| 加盟主開業前因不可歸責事由無法取得工廠登記 | 可解除；加盟金扣除已發生之訓練成本（上限 15 萬）後退還，保證金全退 |
| 重大食安、添加違禁物、擅跨區設廠 | 總部得終止，保證金沒收，並得請求懲罰性違約金（律師定稿） |
| 連續 6 個月未依約繳系統費 | 催告 15 日後得終止 |
| 契約期滿不續 | 停止商標、處理剩餘印有商標之包材（90 日內銷燬或塗銷），保證金退還 |
| 總部變更系統費或其他重大義務 | 須書面合意；不得單方減損專屬區 |

## 補充揭露（建議主動提供，降低爭議）

1. **體系家數：** 截至揭露日，工廠加盟 0 家；宜蘭直營製造 1 處；展示／餐飲門市現況由總部據實列出（含地址）。  
2. **上一年度解除或終止比率：** 工廠體系尚無前一年度數據；若提及舊門市加盟，應另表列出已知據點與是否仍營業，禁止只秀「曾開過」的店。  
3. **訴訟與裁罰：** 據公開彙整，商業登記未見食安裁罰紅旗；正式揭露應再查食藥署與公平會。  
4. **投資風險：** 冰品淡旺季明顯；本事業可能虧損、可能無法回收投資。  
5. **不得宣傳：** 保證收益、保證回本、保證經銷家數。
