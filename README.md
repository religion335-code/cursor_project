# 宜蘭烤肉飯

炭火便當店的網站：菜單、外帶點餐、店內看板。資料存在瀏覽器 `localStorage`，沒有後端，可以丟上 Cloudflare Pages。

店名、地址、LINE、營業時段在 `src/shop.ts`；價格與品項在 `src/menu.ts`。這份預設是宜蘭火車站附近的獨立炭火舖，不是連鎖店官網。

## 跑起來

```bash
npm install
npm test
npm run dev
```

| 頁面 | 做什麼 |
| --- | --- |
| `/` | 現在幾點開沒開、今日湯、常點 |
| `/menu` | 便當／加料／湯／飲料，加入外帶 |
| `/order` | 醬量、取餐時段、留姓名電話 |
| `/shop` | 地址、時間、內用說明 |
| `/kitchen` | 自動烤肉架、取餐隊列、標記售完 |

營業判斷用 `Asia/Taipei`。週一到週六午餐 `10:30–13:30`、晚餐 `16:30–19:30`，週日公休。打烊後仍可預訂下一爐。

自動烤肉架有六鉤：便當肉自動上鉤、馬達翻面、時間到訂單變「可取餐」。預設 30 倍加速方便示範（里肌 4 分鐘 → 8 秒）；看板可切回現場速度。湯、飲料、蛋不上架。

## 注意

訂單不會送到真實廚房。現場對號請開同一台裝置的「店內看板」。數字是 2026 年便當店常見價位，不是某間實體店的官價。
