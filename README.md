# 空間風量（CMF / CFM）計算

台灣設備規格常把 **CFM**（立方英尺／分鐘）寫成 **CMF**。

## 這次的條件

- 空間 **700 × 400 × 500 mm**（0.14 m³／140 L）
- 抽風管直徑 **35 mm**
- 吸引風速 **15 m/s**（管內輸送／吸引風速）

集塵機總風量用風管斷面積 × 風速，不是用房間換氣次數。

## 答案：30.6 CMF

\[
A = \pi d^2 / 4 = \pi \times 0.035^2 / 4 = 0.000962\ \mathrm{m}^2\ (9.62\ \mathrm{cm}^2)
\]

\[
Q = v \times A = 15 \times 0.000962 = 0.01443\ \mathrm{m}^3/\mathrm{s}
\]

| 單位 | 總風量 |
| --- | ---: |
| **CMF / CFM** | **30.6** |
| CMH（m³/h） | 52.0 |
| CMM（m³/min） | 0.866 |

對 0.14 m³ 箱體，這個風量約 **9.7 秒換氣一次**（ACH ≈ 371）。

風量與直徑平方成正比：相對 Ø50 mm 的 62.4 CMF，Ø35 mm 約為 \((35/50)^2 = 49\%\)，所以是 30.6 CMF。

選機請選能在濾網與 35 mm 管阻力下仍提供 **≥ 30.6 CMF** 的集塵機；積塵後風量會掉，實務常選額定 **40–60 CMF**。35 mm 管在 15 m/s 時壓損比 50 mm 高，靜壓更要留餘裕。

15 m/s 適合木屑、輕粉塵輸送。更重的粉塵常見 18–23 m/s。
