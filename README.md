# 空間風量（CMF / CFM）計算

台灣設備規格常把 **CFM**（cubic feet per minute，立方英尺／分鐘）寫成 **CMF**。本工具把兩者視為同一單位。

這次任務沒有附上平面圖或長寬高，因此無法對「某一個特定房間」給出單一數字。請用 `index.html` 輸入坪數，或先看下面的常見空間速查。

## 怎麼算

1. 室積 \(V\)（m³）= 坪數 × 3.305785 × 層高  
   或 \(V\) = 長 × 寬 × 高
2. 換氣風量 **CMH**（m³/h）= \(V\) × ACH（每小時換氣次數）
3. 人數新鮮空氣 **CMH** = 人數 × 25
4. 需求風量取兩者較大值
5. **CFM / CMF** = CMH × 0.5886  
   **CMM** = CMH ÷ 60
6. 選型風量再加 20% 餘裕（風管、濾網、漏風）

客廳、臥室預設 ACH = 5；廚房 12；衛浴 8。這是**通風／循環換氣**估算，不是冷氣噸數。

## 常見空間速查

預設層高 2.7 m（衛浴 2.4 m），含 20% 選型餘裕：

| 空間 | ACH | 需求 CFM | 選型 CFM | 需求 CMH |
| --- | ---: | ---: | ---: | ---: |
| 臥室 4 坪 | 5 | 105.1 | 126.1 | 178.5 |
| 臥室 6 坪 | 5 | 157.6 | 189.1 | 267.8 |
| 客廳 8 坪 | 5 | 210.1 | 252.2 | 357.0 |
| 客廳 12 坪 | 5 | 315.2 | 378.2 | 535.5 |
| 廚房 3 坪 | 12 | 189.1 | 226.9 | 321.3 |
| 衛浴 2 坪 | 8 | 74.7 | 89.7 | 126.9 |
| 辦公室 10 坪 | 6 | 315.2 | 378.2 | 535.5 |
| 會議室 15 坪 | 8 | 630.4 | 756.5 | 1071.1 |

精確值以計算機為準。浴室間歇排氣常見下限約 50 CFM。

## 使用方式

用瀏覽器開啟 `index.html`，或在專案根目錄執行：

```bash
python3 -m http.server 4173
```

然後打開 http://127.0.0.1:4173/

公式單元測試：

```bash
node --test tests/cfm.test.js
```
