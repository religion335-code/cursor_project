# 空間風量（CMF / CFM）計算

台灣設備規格常把 **CFM**（立方英尺／分鐘）寫成 **CMF**。

## 這次的條件

- 空間 **700 × 400 × 500 mm**（0.14 m³／140 L）
- 抽風管直徑 **50 mm**
- 吸引風速 **15 m/s**（管內輸送／吸引風速）

集塵機總風量用風管斷面積 × 風速，不是用房間換氣次數。

## 答案：62.4 CMF

\[
A = \pi d^2 / 4 = \pi \times 0.050^2 / 4 = 0.001963\ \mathrm{m}^2\ (19.63\ \mathrm{cm}^2)
\]

\[
Q = v \times A = 15 \times 0.001963 = 0.02945\ \mathrm{m}^3/\mathrm{s}
\]

| 單位 | 總風量 |
| --- | ---: |
| **CMF / CFM** | **62.4** |
| CMH（m³/h） | 106.0 |
| CMM（m³/min） | 1.77 |

對 0.14 m³ 箱體，這個風量約 **4.8 秒換氣一次**（ACH ≈ 757）。

選機請選能在濾網與 50 mm 管阻力下仍提供 **≥ 62.4 CMF** 的集塵機；積塵後風量會掉，實務常選額定 **80–100 CMF**。餘裕加在靜壓，不要把管內風速再往上加，否則 50 mm 管會更吵、壓損更大。

15 m/s 適合木屑、輕粉塵輸送。更重的粉塵常見 18–23 m/s。
