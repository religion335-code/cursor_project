# 蘭陽雲工

以 **十萬新台幣** 在 **台灣宜蘭** 起步的一人工作室作業系統：用 Agent AI 交件、用 Cloud 當廠房、用遠距把案件送到全台與海外。

這個 repo 原本只有一行標題。現在它是一份可跑的程式：對外是作品集，對內是跑道、報價、看板與本地策劃 Agent。

## 這份程式在做什麼

| 頁面 | 用途 |
| --- | --- |
| 首頁 | 定位：宜蘭據點、十萬資本、三個支柱 |
| 跑道 | 可調整的生活／工具／雲端成本，重算月燒與可撐月數 |
| 方案 | 火花診斷 18,000、可交件 Agent 48,000、月費守夜 12,000，可開報價 |
| 工作室 | 案件看板、遠距週儀式、已存報價 |
| Agent | 不上雲的策劃引擎，用你目前的數字回答問題 |

資料存在瀏覽器 `localStorage`，不需後端、不需 API 金鑰。沒有案件時不必為了問自己問題而付 token。

## 為什麼這樣設計

十萬不是種子輪，是生活跑道。預設假設：

- 據點在宜蘭／羅東，不是台北租屋
- Cloudflare Pages、Worker、信箱轉寄先吃免費額度
- Cursor 當核心生產工具
- 先賣診斷再賣建置，再用月費把本金從「薪水」變成「緩衝」
- 九十天目標是開出第一張帳單，不是做平台

數字是 **2026 年規劃假設**，不是會計或法律意見。租金、健保、稅務請用跑道頁改成你的實際數字。

## 本機執行

需要 Node.js 20+。

```bash
npm install
npm test
npm run dev
```

瀏覽器打開 <http://localhost:5173>。

```bash
npm run build
npm run preview
```

## 免費部署

把 `npm run build` 的 `dist/` 丟到 **Cloudflare Pages**（或同等靜態託管）。SPA 需把所有路徑指到 `index.html`。自有網域加上 Email Routing 之後，對外就可以用工作室信箱，月費仍可以是 0。

## 技術

Vite、React 19、TypeScript。Agent 是讀跑道與套餐的規則引擎，不是外連模型。之後若接 OpenAI 相容 API，應等第一張發票進來再打開用量。
